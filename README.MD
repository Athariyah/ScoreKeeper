# ScoreKeeper

Приложение для ведения счёта спортивных матчей (**волейбол** и **большой теннис**) с отдельным табло для зрителей. Оператор управляет счётом на ноутбуке, а табло автоматически выводится на телевизор или проектор, подключённый по HDMI.

Все релизы: [github.com/Athariyah/ScoreKeeper/releases](https://github.com/Athariyah/ScoreKeeper/releases)

### Установка

1. Скачайте `ScoreKeeper-Setup.exe` по ссылке выше и запустите его.
2. Следуйте мастеру установки. Права администратора не нужны, программа ставится в папку пользователя (`%LOCALAPPDATA%\Programs\ScoreKeeper`).
3. При желании отметьте ярлык на рабочем столе.
4. Запустите **ScoreKeeper** из меню «Пуск» или с рабочего стола.

Устанавливать Python или Java отдельно не нужно, всё необходимое уже внутри. Если Windows покажет предупреждение о неизвестном издателе, нажмите «Подробнее» и «Выполнить в любом случае».

## Возможности

- Счёт волейбола и тенниса по правилам: очки, партии и геймы, сеты, тай-брейк, подача.
- Экран оператора: добавление очка, **откат** последнего очка, **сброс**, **корректировка** счёта вручную, завершение матча.
- Предпросмотр табло прямо на экране оператора.
- **Вывод на телевизор по HDMI**: при подключении второго экрана табло открывается на нём само, на весь экран и без рамок. Ноутбук остаётся экраном оператора. Табло появляется, как только открыт экран счёта, даже до нажатия «Начать матч».
- Бегущий текст на табло («Вывести текст»).
- Названия и логотипы команд, логотипы организаций на табло.
- Интерфейс на русском и английском языках.

## Вывод на телевизор

1. Подключите телевизор или проектор к ноутбуку кабелем HDMI.
2. Убедитесь, что включён режим экранов **«Расширить»** (Win+P → Расширить). Приложение переключает его само при запуске.
3. Откройте экран счёта (волейбол или теннис). Табло появится на телевизоре.
4. Выход в главное меню или отключение кабеля закрывает табло.

Если телевизор показывает то же, что и ноутбук, значит включён режим «Дублировать». Нажмите Win+P и выберите «Расширить».

## Правила

**Волейбол.** Матч до 2 выигранных партий. Партия идёт до 25 очков, решающая третья до 15, в обоих случаях с разницей минимум в 2 очка.

**Теннис.** Очки 0 / 15 / 30 / 40 / преимущество, сет до 6 геймов с разницей в 2, при 6:6 тай-брейк до 7 очков. Матч до 2 выигранных сетов.

## Для разработчиков

### Как устроено

Приложение состоит из двух частей, которые общаются по HTTP и WebSocket на `127.0.0.1`.

| Часть | Технологии | Назначение |
|---|---|---|
| `backend/` | Python, FastAPI, Uvicorn | Логика матча: движки волейбола и тенниса, REST API, WebSocket |
| `frontend/` | Kotlin, Compose Desktop, Ktor | Интерфейс оператора и табло для зрителей |
| `tools/windows/` | C#, Inno Setup | Лаунчер и установщик для Windows |

В установленной версии лаунчер `ScoreKeeper.exe` сам находит свободный порт (начиная с 8000), запускает бэкенд, ждёт его готовности, затем запускает интерфейс и передаёт ему порт через переменную `SCOREKEEPER_PORT`. При закрытии интерфейса бэкенд останавливается.

### Запуск из исходников

Нужны Python 3.10+ и JDK 17+.

```bash
# 1. Бэкенд (из корня репозитория)
python -m venv venv
venv\Scripts\activate          # Windows
pip install fastapi "uvicorn[standard]" pydantic
python run.py                  # 127.0.0.1:8000, логи в server.log

# 2. Интерфейс (в другом терминале)
cd frontend
gradlew run                    # Windows: gradlew.bat run
```

Без `SCOREKEEPER_PORT` интерфейс подключается к порту по умолчанию (8000).

### Сборка установщика (Windows)

1. Соберите бэкенд в один `.exe` через PyInstaller (`ScoreKeeperBackend.spec`) и назовите его `ScoreKeeperAppBackend.exe`.
2. Соберите интерфейс: `gradlew createDistributable` в папке `frontend`.
3. Скомпилируйте лаунчер `tools/windows/ScoreKeeperLauncher.cs` в `ScoreKeeper.exe`.
4. Соберите папку `ScorekeeperAppRelease` в корне репозитория:
   ```
   ScorekeeperAppRelease/
   ├── ScoreKeeper.exe                      # лаунчер
   ├── BackendRelease/ScoreKeeperAppBackend.exe
   └── FrontendRelease/ScoreKeeper/ScoreKeeper.exe
   ```
5. Откройте `tools/windows/ScoreKeeperInstaller.iss` в [Inno Setup](https://jrsoftware.org/isinfo.php) и скомпилируйте. Готовый `ScoreKeeper-Setup.exe` появится в `installer-output/`.

### API

Базовый URL: `http://127.0.0.1:8000/api/match`, WebSocket: `ws://127.0.0.1:8000/ws/match`.

| Метод | Путь | Назначение |
|---|---|---|
| POST | `/start` | Начать матч (вид спорта, имена, кто подаёт) |
| GET | `/state` | Текущее состояние матча |
| POST | `/point` | Добавить очко игроку |
| POST | `/remove-point` | Откатить последнее очко |
| POST | `/set-score` | Выставить счёт вручную |
| POST | `/reset` | Сбросить матч |
| POST | `/force-end` | Принудительно завершить матч |
| POST | `/text` | Отправить текст на табло |

Форматы состояния матча: [docs/api.md](docs/api.md).

## Частые проблемы

| Проблема | Решение |
|---|---|
| Программа не запускается, пишет про backend | Порт занят или антивирус заблокировал `ScoreKeeperAppBackend.exe`. Перезапустите программу, добавьте папку установки в исключения антивируса |
| Табло не появилось на ТВ | Включите режим «Расширить» (Win+P), проверьте кабель HDMI |
| При запуске из исходников кнопки не работают | Не запущен бэкенд, выполните `python run.py` |
