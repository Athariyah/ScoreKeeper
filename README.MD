# ScoreKeeper

**Версия:** `1.1`

**ScoreKeeper** — настольное приложение для ведения спортивного счёта и вывода зрительского табло на внешний экран (ТВ / проектор по HDMI) в матчах по **волейболу** и **большому теннису**.

Разработано в рамках **СНО ФИиИТ ДГУ & АйтиПрорыв Академия** для **Спортивной комиссии ДГУ**.

---

## Возможности

- **Два вида спорта:**
   - **Волейбол** — настройка формата перед игрой (до 3 или 5 партий, пресеты короткой/длинной игры или индивидуальный лимит очков для каждой партии и тай-брейка), учёт подающей команды и текущей партии.
   - **Большой теннис** — автоматический подсчёт очков в гейме (`0`, `15`, `30`, `40`, `AD`), геймов и сетов, смена подающего после гейма.
- **Зрительское табло на втором экране:**
   - Встроенное живое превью табло на экране оператора.
   - Автоматическое открытие полноэкранного табло на подключённом внешнем дисплее (HDMI/ТВ) и переключение Windows в режим расширенного экрана.
   - Вывод текстовых объявлений для зрителей в реальном времени по WebSocket (например, *«Разминка 5 минут»*).
- **Подготовка и контроль матча:**
   - Ввод названий команд / имён игроков и загрузка логотипов.
   - Интерактивная жеребьёвка (подброс монетки) при старте матча.
   - Начисление очков, откат последнего розыгрыша, ручная корректировка счёта, подающего и расположения команд на площадке (`1 | 2` с анимацией смены сторон), сброс и принудительное завершение/продолжение матча.
   - Таймер продолжительности матча.
   - Предупреждение о сбросе счёта при попытке выйти из начатого или завершённого матча.
- **Клавиатурное управление и экран «ХОТКЕИ»:**
   - Полное управление матчем и окнами с клавиатуры (независимо от раскладки `RU` / `EN`) с визуальным откликом кнопок.
   - Интерактивная памятка `ХОТКЕИ` (`H`): при открытом окне хоткеев включается безопасный демонстрационный режим — нажатия проигрывают 3D-анимацию клавиш на схеме, не отправляя команды на сервер (кроме `Esc` для возврата назад).
- **Интерфейс:**
   - Светлая и тёмная темы оформления.
   - Русский (`RU`) и английский (`EN`) языки интерфейса.

## Горячие клавиши

### Кнопки матча

| Клавиша | Действие |
| :--- | :--- |
| `1` | Добавить очко команде / игроку 1 |
| `2` | Добавить очко команде / игроку 2 |
| `-` | Откат последнего очка |
| `Tab` | Открыть окно корректировки счёта |
| `Backspace` (`⌫`) | Сбросить текущий счёт матча |
| `Space` | Начать / продолжить / завершить матч |
| `H` | Открыть окно горячих клавиш |

### Основные

| Клавиша | Действие |
| :--- | :--- |
| `Esc` | Назад / закрыть текущее диалоговое окно |
| `~` (`Ё`) | Открыть / закрыть настройки приложения |
| `F1` | Закрыть приложение |
| `F2` | Свернуть окно приложения |
| `Enter` | Готово / подтвердить действие в диалоге |

> Во время ввода текста в полях (имена команд, счёт в корректировке, текст объявления) игровые горячие клавиши временно отключаются, чтобы не мешать набору.

## Архитектура и стек

Приложение разделено на локальный HTTP/WebSocket-бэкенд с игровой логикой и десктопный клиент на Compose Multiplatform:

- **Frontend (`/frontend`):**
   - Kotlin `1.9.24`, JetBrains Compose Desktop `1.6.11` (Material 3 + кастомная векторная графика и шрифты `Aqum Two`, `Clear Sans`, `Blogger Sans`, `Blue Curve`).
   - Ktor Client `2.3.12` (`CIO`, `ContentNegotiation`, `WebSockets`), `kotlinx.serialization`, Kotlin Coroutines.
- **Backend (`/backend`):**
   - Python 3, FastAPI, Uvicorn, Pydantic.
   - Изолированные движки правил матча (`VolleyballEngine`, `TennisEngine`) на базе `AbstractMatchEngine` и мгновенная рассылка состояния через WebSocket (`/ws/match`).
- **Сборка и поставка под Windows (`/tools/windows`):**
   - `PyInstaller` (`ScoreKeeperBackend.spec`) — упаковка бэкенда в исполняемый файл.
   - `Compose Desktop Native Distributions` — сборка нативного образа фронтенда (`MSI` / `Dmg` / `Deb`).
   - `ScoreKeeperLauncher.cs` — единый лаунчер, автоматически подбирающий свободный локальный порт (`SCOREKEEPER_PORT`), поднимающий бэкенд и запускающий интерфейс.
   - `ScoreKeeperInstaller.iss` — скрипт установщика Inno Setup.

Подробное описание всех HTTP-эндпоинтов и формата сообщений WebSocket приведено в [`docs/api.md`](docs/api.md).

## Запуск для разработки

### Требования

- **Python** `3.10+`
- **JDK** `17+`

### 1. Запуск бэкенда

Установите зависимости и запустите сервер из корня репозитория:

```bash
pip install fastapi uvicorn pydantic websockets
python run.py --host 127.0.0.1 --port 8000
```

По умолчанию сервер слушает `http://127.0.0.1:8000` (WebSocket: `ws://127.0.0.1:8000/ws/match`) и пишет логи в `server.log`.

### 2. Запуск фронтенда

В отдельном терминале выполните:

```bash
cd frontend
./gradlew run
```

На Windows:

```bat
cd frontend
gradlew.bat run
```

> Если бэкенд запущен на нестандартном порту, передайте его клиенту через переменную окружения `SCOREKEEPER_PORT` (по умолчанию используется `8000`).

### 3. Запуск тестов бэкенда

```bash
python -m unittest discover -s backend/src/tests
```

### 4. Сборка дистрибутива

- **Нативный образ фронтенда:** `cd frontend && ./gradlew createDistributable` (или `packageMsi` / `packageDmg` / `packageDeb`).
- **Исполняемый файл бэкенда:** `pyinstaller ScoreKeeperBackend.spec`.
- **Windows-инсталлятор:** компиляция лаунчера `tools/windows/ScoreKeeperLauncher.cs` и сборка установочного пакета через Inno Setup (`tools/windows/ScoreKeeperInstaller.iss`).

## Справочник правил счёта

### Большой теннис

Счёт в матче строится по иерархии: **очки → геймы → сеты → матч**.

1. **Очки внутри гейма:**

   | Выигранные мячи | Отображаемый счёт |
      | :---: | :---: |
   | `0` | `0` (*Love*) |
   | `1` | `15` |
   | `2` | `30` |
   | `3` | `40` |
   | `4+` (с разницей ≥ 2) | Победа в гейме |

2. **«Ровно» (*Deuce*) и «Больше» (*Advantage*):**
   - При счёте по 3 выигранных мяча (`40:40`) наступает *Deuce* («ровно»).
   - Следующий выигранный мяч даёт преимущество — `AD:40` или `40:AD`.
   - Второй выигранный мяч подряд приносит победу в гейме; если же мяч выигрывает соперник, счёт возвращается к `40:40`.

3. **Геймы, сеты и матч:**
   - После каждого завершённого гейма право подачи переходит к сопернику.
   - Для победы в сете необходимо выиграть минимум **6 геймов** с преимуществом не менее **2 геймов** (например, `6:0`, `6:4`, `7:5`); при `6:6` в классических правилах разыгрывается тай-брейк до 7 очков с разницей минимум в 2 очка.
   - Матч в ScoreKeeper играется до **2 выигранных сетов** (формат *best of 3*).

### Волейбол

Счёт строится по иерархии: **очки → партии (сеты) → матч** по системе *Rally Point* (каждый розыгрыш приносит 1 очко независимо от того, чья была подача; команда, выигравшая розыгрыш, получает право следующей подачи).

1. **Партия (сет):**
   - По стандартным правилам партия идёт до **25 очков** при обязательном преимуществе минимум в **2 очка** (например, `25:20`, `25:23`, `26:24`, `30:28`).
2. **Решающая партия (тай-брейк):**
   - При равном счёте по партиям перед финальным сетом разыгрывается укороченная решающая партия (по умолчанию — до **15 очков** с разницей минимум в **2 очка**, например `15:11` или `17:15`).
3. **Гибкая настройка в ScoreKeeper:**
   - Перед началом волейбольного матча можно выбрать игру **до 3 партий** (до 2 побед) или **до 5 партий** (до 3 побед), включить пресет короткой/длинной игры либо задать произвольное число очков для каждой партии и тай-брейка.
